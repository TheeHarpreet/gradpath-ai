# Graduate Full-Stack Software Engineer

Fictional vacancy for evaluation only.

## About the role {#jd-about}

Northstar Digital builds internal workflow products for UK organisations. The
graduate engineer will work with designers, engineers, and product colleagues
to deliver small, well-tested product improvements.

## Essential requirements {#jd-essential}

1. Practical JavaScript or TypeScript development experience.
2. Experience building user interfaces with React or a comparable framework.
3. Ability to build or consume REST APIs using Python, Java, or TypeScript.
4. Understanding of relational databases and SQL.
5. Experience using Git and participating in code review.
6. Evidence of automated testing.
7. Clear written and verbal communication in a collaborative team.

## Desirable requirements {#jd-desirable}

8. Experience using Docker for local development or deployment.
9. Familiarity with CI/CD workflows.
10. Exposure to AWS cloud services.
11. Familiarity with Kubernetes.

## Additional information {#jd-additional}

This is an entry-level role. Commercial experience is helpful but is not
required. Applicants must be able to explain the technical decisions in their
projects.
