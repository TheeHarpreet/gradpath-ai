# Architecture Decision Records

Architecture Decision Records (ADRs) capture important choices, their context,
the alternatives considered, and their consequences. They prevent the project
from presenting technology choices as unexplained preferences.

## Status values

- Proposed: under active review.
- Accepted: the current implementation direction.
- Superseded: replaced by a later ADR, retained for historical context.
- Rejected: considered but not selected.
